# Northstar Enterprise Network

A simulated multi-site enterprise network designed and documented from the ground up.

## Overview

Northstar Services is a fictional organization with a headquarters (HQ) and two branch offices.

The objective of this project is to design a scalable and resilient network infrastructure based on the organization's technical and business requirements.

The project documents the complete network engineering process, including network requirements, architecture decisions, IP addressing, VLAN design, device configuration, routing, redundancy, security, and validation.

## Network Scope

- Headquarters (HQ)
- Branch 1
- Branch 2
- Multi-site connectivity
- Redundant HQ infrastructure

## Design Approach

The network is being developed progressively, with each design decision documented before implementation.

The HQ network will use a two-tier collapsed core architecture with redundant Layer 3 switches providing the core and distribution functions.
